## Design

### 1. Migration SQL（0014_atom_comments.sql）

```sql
-- Migration: 0014_atom_comments.sql
-- Purpose: S1-R11 ruling — add atom_comments as independent association entity.
-- Invariants:
-- - comment_id: UUIDv4, generated by Core, immutable primary key.
-- - atom_uuid: foreign key to atoms(uuid); cascade soft-delete via trigger.
-- - content: non-empty text; emptiness validated at service layer before insert.
-- - is_deleted: soft-delete marker (0 or 1); no hard-delete in business path.
-- - created_at: epoch ms, set at insert, immutable (no updated_at — append-only).
-- Backward compatibility:
-- - additive schema update on top of migration 0013.

CREATE TABLE atom_comments (
    comment_id  TEXT    PRIMARY KEY NOT NULL,
    atom_uuid   TEXT    NOT NULL
        REFERENCES atoms(uuid),
    content     TEXT    NOT NULL,
    created_at  INTEGER NOT NULL
        DEFAULT (strftime('%s', 'now') * 1000),
    is_deleted  INTEGER NOT NULL DEFAULT 0
        CHECK (is_deleted IN (0, 1))
);

CREATE INDEX IF NOT EXISTS idx_atom_comments_atom_uuid_created
    ON atom_comments(atom_uuid, is_deleted, created_at, comment_id);

-- Cascade soft-delete: when host atom is soft-deleted, soft-delete all its comments.
CREATE TRIGGER atom_comments_cascade_soft_delete
AFTER UPDATE OF is_deleted ON atoms
WHEN NEW.is_deleted = 1 AND OLD.is_deleted = 0
BEGIN
    UPDATE atom_comments
    SET is_deleted = 1
    WHERE atom_uuid = OLD.uuid
      AND is_deleted = 0;
END;
```

**设计说明：**

- `atom_comments` 无 `updated_at` 列（append-only；soft-delete 不修改 content，无需追踪变更时间）
- `CASCADE` 采用触发器而非 `ON DELETE CASCADE`，理由：atoms 表使用 soft-delete，不存在物理行删除事件；触发器响应 `is_deleted` 状态翻转，语义精确
- `idx_atom_comments_atom_uuid_created` 覆盖最常见查询：按 `atom_uuid` 过滤 + 按 `created_at` 升序分页

### 2. Comment 领域模型（`crates/lazynote_core/src/model/comment.rs`）

```rust
/// Stable UUIDv4 comment identifier.
pub type CommentId = Uuid;

/// A time-ordered annotation attached to one atom.
///
/// # Invariants
/// - `comment_id` is never nil; generated by Core on creation.
/// - `content` is never empty (enforced by `CommentService`).
/// - `created_at` is epoch milliseconds; immutable after creation.
/// - Soft-delete path: set `is_deleted = true`; never hard-delete in business code.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Comment {
    pub comment_id: CommentId,
    pub atom_uuid: AtomId,
    pub content: String,
    pub created_at: i64,
    pub is_deleted: bool,
}
```

### 3. CommentRepository trait + SqliteCommentRepository

```rust
/// Query options for listing comments on a single atom.
#[derive(Debug, Clone, Default)]
pub struct CommentListQuery {
    /// Filter by host atom id.
    pub atom_uuid: AtomId,
    /// Maximum rows to return.
    pub limit: Option<u32>,
    /// Number of rows to skip from the ordered result set.
    pub offset: u32,
}

/// Repository interface for atom comment operations.
pub trait CommentRepository {
    /// Inserts a new comment and returns its stable ID.
    fn create_comment(&self, comment: &Comment) -> RepoResult<CommentId>;

    /// Lists non-deleted comments for one atom, ordered `created_at ASC`.
    fn list_comments(&self, query: &CommentListQuery) -> RepoResult<Vec<Comment>>;

    /// Soft-deletes a comment by ID.
    ///
    /// Idempotent: already-deleted comments succeed silently.
    /// Returns [`RepoError::NotFound`] when `comment_id` does not exist at all.
    fn soft_delete_comment(&self, comment_id: CommentId) -> RepoResult<()>;
}
```

`SqliteCommentRepository` 实现细节：
- `try_new(conn)` 校验 schema version 与 `atom_comments` 表存在（与 `SqliteAtomRepository::try_new` 相同模式）
- `create_comment`：`INSERT INTO atom_comments` + info log `event=comment_create`
- `list_comments`：`WHERE atom_uuid = ? AND is_deleted = 0 ORDER BY created_at ASC, comment_id ASC LIMIT ? OFFSET ?`
- `soft_delete_comment`：`UPDATE atom_comments SET is_deleted = 1 WHERE comment_id = ? AND is_deleted = 0`；`changed == 0` 时判断行是否存在（与 `soft_delete_atom` 模式一致）

RepoError 复用现有 `RepoError` 类型；`NotFound` 变体改为接受 `CommentId` 需扩展枚举或新增 `CommentRepoError`（具体见实现阶段决策，以保持最小改动为优先）。

### 4. CommentService

```rust
/// Atom comment CRUD service.
///
/// Thin orchestration layer: validates content non-emptiness,
/// generates UUIDs, delegates persistence to `CommentRepository`.
pub struct CommentService<'conn> {
    repo: SqliteCommentRepository<'conn>,
}

impl<'conn> CommentService<'conn> {
    pub fn try_new(conn: &'conn Connection) -> Result<Self, CommentServiceError>;

    /// Creates one comment on the given atom.
    ///
    /// # Errors
    /// - `EmptyContent` when `content` is blank after trimming.
    /// - `AtomNotFound` when `atom_uuid` does not exist or is soft-deleted.
    pub fn add_comment(
        &self,
        atom_uuid: AtomId,
        content: String,
    ) -> Result<Comment, CommentServiceError>;

    /// Lists non-deleted comments for one atom (time-ordered, paginated).
    pub fn list_comments(
        &self,
        atom_uuid: AtomId,
        limit: Option<u32>,
        offset: u32,
    ) -> Result<Vec<Comment>, CommentServiceError>;

    /// Soft-deletes a comment by ID.
    ///
    /// Returns `CommentNotFound` when no comment exists with the given ID.
    pub fn delete_comment(
        &self,
        comment_id: CommentId,
    ) -> Result<(), CommentServiceError>;
}

#[derive(Debug)]
pub enum CommentServiceError {
    EmptyContent,
    AtomNotFound(AtomId),
    CommentNotFound(CommentId),
    Db(RepoError),
}
```

`add_comment` 内部流程：
1. `content.trim()` 非空校验 → `EmptyContent`
2. 查询 `atoms WHERE uuid = ? AND is_deleted = 0` 确认 atom 存在（`AtomNotFound`）
3. `Uuid::new_v4()` 生成 `comment_id`
4. 构建 `Comment { comment_id, atom_uuid, content, created_at: now_ms(), is_deleted: false }`
5. `repo.create_comment(&comment)` → 返回 `Comment`

**新增 FFI 函数：**

```rust
/// Creates a comment on the given atom.
///
/// # FFI contract
/// - Async call, DB-backed execution.
/// - `caller`: CallerContext JSON string (consistent with PR-0411 convention).
/// - `content` must not be blank after trimming; returns `empty_content` on violation.
/// - `atom_id` must reference a non-deleted atom; returns `atom_not_found` otherwise.
/// - Returns `CommentItemResponse` with the created comment on success.
/// - Never panics.
#[flutter_rust_bridge::frb]
pub async fn comment_create(
    caller: String,
    atom_id: String,
    content: String,
) -> CommentItemResponse;

/// Lists non-deleted comments for one atom in chronological order.
///
/// # FFI contract
/// - Async call, DB-backed execution.
/// - `limit` defaults to 50; maximum 200.
/// - `offset` defaults to 0.
/// - Returns `CommentListResponse` (empty list when atom has no comments).
/// - Never panics.
#[flutter_rust_bridge::frb]
pub async fn comments_list(
    caller: String,
    atom_id: String,
    limit: Option<u32>,
    offset: Option<u32>,
) -> CommentListResponse;

/// Soft-deletes a comment by ID.
///
/// # FFI contract
/// - Async call, DB-backed execution.
/// - Idempotent: deleting an already-deleted comment returns ok=false, error_code=`comment_not_found`.
/// - Returns `comment_not_found` when no comment exists with the given ID.
/// - Never panics.
#[flutter_rust_bridge::frb]
pub async fn comment_delete(
    caller: String,
    comment_id: String,
) -> CommentItemResponse;
```

| 变体 | error_code |
|------|-----------|

### 7. Cascade Soft-Delete 行为矩阵

| 操作 | atom.is_deleted 变化 | comment.is_deleted 结果 |
|------|----------------------|------------------------|
| atom soft-delete（`soft_delete_atom`） | 0 → 1 | 触发器将所有相关 comment 置 1 |
| atom 已经是 deleted（重复调用） | 无变化（is_deleted=1 → 1） | 触发器 WHEN 条件不满足，不触发 |
| comment 单独 soft-delete | atom 不受影响 | comment.is_deleted = 1 |
| atom 恢复（未来功能，当前不实现） | N/A | N/A |

触发器采用 `AFTER UPDATE OF is_deleted ON atoms WHEN NEW.is_deleted = 1 AND OLD.is_deleted = 0`，精确匹配 0→1 状态翻转，避免幂等调用触发意外 UPDATE。

## Risk

| 风险 | 严重度 | 缓解 |
|------|--------|------|
| Cascade trigger 在 atom soft-delete 幂等调用时意外触发 | LOW | Trigger WHEN 条件精确匹配 `OLD.is_deleted = 0 AND NEW.is_deleted = 1`，幂等调用不满足 WHEN，不触发；负测覆盖 |
