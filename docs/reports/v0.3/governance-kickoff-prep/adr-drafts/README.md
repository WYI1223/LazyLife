# ADR Draft Package

> Prep-layer container for future first-batch retrospective ADR manuscripts.
> This directory does not currently contain approved or promoted ADRs.

---

## Purpose

This directory is reserved for files like:

- `ADR-000X-<slug>-draft.md`

These are kickoff-prep manuscripts only. They are not equivalent to:

- published ADRs;
- formal `docs/architecture/adr/ADR-XXXX-*.md` assets;
- normative governance documents.

## Promotion Rule

Only future kickoff mainline work may decide whether a prep-layer ADR draft becomes:

1. a promoted ADR asset;
2. a rewritten draft after split / merge resolution;
3. a deferred manuscript that stays in prep history.
