# v0.3 Governance Kickoff Prep

> 承载 `DI-19` / `DI-20` 派生出的治理 kickoff 前筹备文档。
> 这些文件不是普通 design discussion，也不是长期规范源；它们是为后续
> `v0.4 kickoff` 组织正式 PR spec 时准备的参考输入与 handoff 材料。

---

## 目录职责

本目录用于存放：

1. `PR-GOV-*` 候选 PR spec 草案
2. `source corpus inventory`
3. `theme map / coverage baseline`
4. `template extraction backlog`
5. future kickoff mainline 可能采用的 skeleton、draft 与 closure 输入

本目录不承载：

1. `DI` 讨论与裁决正文
2. 长期规范源（`Ruling` / Native ADR）
3. 已经沉淀为稳定模板的长期资产
4. 已正式进入 `docs/releases/v0.4/` 主线的执行文档
